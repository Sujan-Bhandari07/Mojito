## 📖 About

Mojito is a showcase website for a cafe and restaurant. It pairs a React frontend with GSAP animations to create a lively, visually rich experience.

## 🚢 Deployment

Mojito is deployed on [Render](https://render.com/) as a static site.

1. Create a new **Static Site** on Render and connect this repository.
2. Set the build command to `npm install && npm run build`.
3. Set the publish directory to your build output folder.
